# بررسی مستندات عمومی BoxAPI دربارهٔ مدیریت پیج و تمدید اشتراک

تاریخ بررسی: ۱۲ نوامبر ۲۰۲۶

## جمع‌بندی اجرایی

1. برای API رسمی دایرکت/کامنت، مستندات عمومی صفحه‌های پلن‌های پایه (۱ پیج)، استارتاپ (۲ تا ۵ پیج)، کسب‌وکار (۶ تا ۳۰ پیج) و همکاری (بیش از ۳۰ پیج با قیمت توافقی) را معرفی می‌کند. در صفحهٔ قیمت‌گذاری، پلن نامحدود صریحاً فهرست نشده است؛ پلن همکاری برای ظرفیت بالاتر نیازمند هماهنگی است.
2. ساخت یک اتصال جدید در گردش مستندشده از طریق لینک OAuth اختصاصی (`instagram_oauth_url`) و ورود/رضایت صاحب پیج انجام می‌شود. فهرست پیج‌های متصل از `GET /service/accounts` قابل خواندن است؛ این endpoint پیج را خودش ایجاد یا وارد حساب نمی‌کند.
3. یک API خرید مستندشده وجود دارد: API سقف پیج برای **کاربران سازمانی** در `https://boxapi.ir/wallet/v1`. این API ظرفیت مجاز را افزایش/کاهش می‌دهد؛ پیج اینستاگرام را OAuth نمی‌کند و طبق مستندات، تمدید اشتراک ماهانهٔ یک پیج خاص هم نیست.
4. در مستندات عمومی‌ای که بررسی شد endpointی برای خرید/تمدید پلن عادی یا تمدید مجزای یک `account_id` مشخص پیدا نشد. نتیجهٔ امن: از API عمومی فعلی نمی‌توان چنین قابلیتی را قطعی دانست؛ برای صورتحساب per-page و تمدید باید از پشتیبانی BoxAPI قرارداد/endpoint رسمی گرفت.
5. فیلد `expires_at` در خروجی `/service/accounts` طبق مستند، **انقضای دسترسی/اتصال پیج** است و در صورت انقضا باید ورود مجدد انجام شود؛ این فیلد را نباید با پایان پلن تجاری BoxAPI یکی گرفت.

## مسیر افزودن پیج به سرویس

در مدل فعلی کد ما، فرایند چنین است:

1. کاربر در پنل فروش‌یار «ورود به BoxAPI» را می‌زند.
2. صاحب پیج در فرم رسمی BoxAPI/Meta وارد حساب می‌شود و دسترسی OAuth می‌دهد.
3. فروش‌یار `GET /service/accounts` را می‌خواند و پیج‌های واجد شرایط را نمایش می‌دهد.
4. انتخاب کاربر فقط `account_id` پیج را به فروشگاه او متصل می‌کند.

پس API نمایش‌داده‌شده برای فهرست‌کردن پیج‌ها است، نه دورزدن ورود اینستاگرام یا افزودن پیج بدون رضایت صاحبش. افزودن یک انتخاب دیگر در پنل خودمان به‌تنهایی ظرفیت BoxAPI را زیاد نمی‌کند؛ ظرفیت باید از پلن/حساب BoxAPI فراهم باشد.

## API رسمی خرید سقف سازمانی

مستند BoxAPI بخش «API خرید پلن API رسمی اینستاگرام (کاربران سازمانی)» این دو endpoint را مشخص می‌کند:

- `GET /page-limit`: تعداد سقف فعلی (`page_limit`)، پیج‌های مصرف‌شده (`pages_used`)، نرخ روزانهٔ هر پیج و موجودی کیف پول.
- `POST /page-limit`: `action: increase|decrease` و `quantity` تعداد تغییر (۱ تا ۱۰۰۰۰)، نه سقف نهایی.

قواعدی که مستند صریح کرده:

- Bearer token از بخش خرید اعتبار پنل BoxAPI لازم است.
- حساب غیرسازمانی با `403 bpm_not_enterprise` رد می‌شود.
- هنگام افزایش، هزینه همان لحظه از کیف پول کم می‌شود و هزینهٔ روزانه از روز بعد بر اساس سقف جدید محاسبه می‌شود.
- کاهش سقف هزینه را بازپرداخت نمی‌کند و سقف نمی‌تواند از پیج‌های فعال کمتر شود.
- اگر موجودی برای نرخ روزانه کافی نباشد، مستند هشدار می‌دهد سقف ممکن است صفر شود.
- برای `409 bpm_busy` باید بعداً retry کرد؛ برای `502` پیش از تکرار باید وضعیت سقف دوباره خوانده شود.

بنابراین این API می‌تواند در حساب Enterprise برای اضافه‌کردن ظرفیت چند پیج از طریق سرویس ما استفاده شود، اما تضمینی دربارهٔ پرداخت صورتحساب یک مشتری نهایی، تمدید ماهانهٔ فقط پیج او، تمدید authorization آن پیج، یا افزودن خود پیج ندارد.

## پاسخ به پرسش پلن نامحدود

- «نامحدود» را نمی‌توان از منابع عمومی به‌عنوان الزام فنی تأیید کرد.
- صفحهٔ قیمت‌گذاری عمومی بازه‌های ۱، ۲–۵، ۶–۳۰ و همکاری بالای ۳۰ پیج را نشان می‌دهد؛ همکاری قیمت توافقی دارد.
- مسیر مستندشدهٔ API کنترل سقف مخصوص حساب‌های Enterprise/سازمانی است. معلوم نیست حساب فعلی ما از BoxAPI مجوز همین API را دارد یا نه؛ پاسخ HTTP `403 bpm_not_enterprise` این را مشخص می‌کند.
- برای SaaS چندمشتری، پیشنهاد عملی: از BoxAPI نرخ همکاری/Enterprise، نحوهٔ حسابداری per-page و اجازهٔ اجرای API از طرف حساب پلتفرم را کتبی بگیریم؛ صرفاً پلن نامحدود خریدن جای آن قرارداد/مجوز را نمی‌گیرد.

## تمدید پیج موجود

مستند `GET /service/accounts` مقدار `expires_at` را برای هر پیج برمی‌گرداند و می‌گوید در صورت انقضای دسترسی نیاز به ورود مجدد است. این یک جریان re-authentication است، نه endpoint تمدید دورهٔ پولی.

مستند API سقف صفحه هم فقط تعداد مجاز پیج‌ها و هزینهٔ روزانهٔ سقف را دست‌کاری می‌کند؛ پارامتر `account_id` یا `renew` ندارد. بنابراین از مستندات فعلی، نمی‌توان اشتراک یک پیج مشتری را به‌صورت مستقل از طریق API تمدید کرد. باید از BoxAPI پرسید آیا:

- endpoint خصوصی/همکاری برای تمدید «یک پیج/یک account_id» دارند؛
- تمدید فقط از پنل انجام می‌شود یا با شارژ کیف پول Enterprise خودکار است؛
- `expires_at` با تمدید مالی تغییر می‌کند یا فقط با OAuth مجدد؛
- امکان sub-account یا white-label billing برای SaaS مجاز است.

## دامنهٔ بررسی و محدودیت

مستندات عمومی قابل دسترسی وب شامل مستند API دایرکت/کامنت، فهرست پیج‌های متصل، اطلاعات حساب `/api/my`، مستند خرید سقف پیج Enterprise و صفحهٔ قیمت‌گذاری بررسی شد. مستندات/قراردادهای خصوصی پنل حساب BoxAPI، endpointهای داخلی فروش و دسترسی حساب کاربری فروش‌یار در دسترس این بررسی نبودند؛ بنابراین ادعای «هیچ API خصوصی وجود ندارد» نمی‌کنیم.
