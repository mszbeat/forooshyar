# اجرای الگوها در اپ واقعی

این پوشه «مرجع» است؛ این فایل توضیح می‌دهد چه چیزی از آن تحقیق **واقعاً در کد محصول** پیاده شد و کجا.

## نقشه‌ی تغییرات

| فایل | چه شد |
|---|---|
| `frontend/app/fonts.css` | وزن **300 (Light)** وزیرمتن اضافه شد. تا قبل از این فقط ۴۰۰/۵۰۰/۶۰۰/۷۰۰/۸۰۰ بود و تیتر نازک اصلاً رندر نمی‌شد. |
| `frontend/public/fonts/Vazirmatn-Light.woff2` | فونت اضافه شد (49KB). |
| `frontend/app/globals.css` | بازتنظیم سیستم طراحی (بخش ۱ توکن‌ها + بخش ۴ کامپوننت‌ها) — جزئیات پایین. |
| `frontend/app/landing.css` | از نو نوشته شد: ناوبری ۶۴px چسبان، هیرو دو ستونی با گرادیان بیرون‌زننده، نوار آمار هایرلاین، گرید ۶ سلولی، بخش تیره، آکاردئون، CTA وسط‌چین، فوتر ۴ ستونی + بلوک auth که از این فایل استفاده می‌کند. |
| `frontend/app/page.tsx` | لندینگ با همان محتوا اما ساختار بخش‌های کپی‌شده + بخش پرسش‌های متداول + فوتر کامل. |
| `frontend/app/app/layout.tsx` | در موبایل عنوان فروشگاه در تاپ‌بار دیده می‌شود (قبلاً پنهان می‌شد و تاپ‌بار خالی بود). |

## تغییرات توکن‌ها (globals.css)

| مورد | قبل | بعد | چرا |
|---|---|---|---|
| رمپ خنثی | سبز-خاکستری (`#f6f8f7`, `#e4eae7`) | آبی-خاکستری (`#f7f9fc`, `#e5edf5`) | Stripe: خنثی مایل به آبی، هیچ‌وقت سفید/خاکستری خالص |
| متن | `#0c1e1a` | `#061b31` | متن تیتر هرگز سیاه نیست؛ سرمه‌ای تیره |
| شعاع | `8/10/14/18/24` | `4/6/8/10/14` | گوشه‌ی گرد = ارزان‌تر به نظر می‌رسد |
| سایه‌ی کارت | `--sh-sm` روی هر کارت | حذف شد → `1px solid var(--line)` | FlowNinja: تفکیک با خط مویی |
| سایه | فقط برای لایه‌های شناور (`--sh-md`, `--sh-lg`) | همان | دراپ‌داون/مودال/توست |
| دکمه | گرادیان + `translateY(-1px)` در هاور + سایه‌ی رنگی | پرِ تخت `var(--brand)`، بدون جابه‌جایی، هاور = یک پله تیره‌تر | Stripe: هیچ لفتی در هاور |
| وزن تیتر | `700` | `h1/h2` = ۳۰۰، `h3` = ۵۰۰ | مهم‌ترین برداشت از هر دو مرجع |
| فوکوس | `box-shadow` دوتایی | `outline: 3px solid rgba(15,122,106,.45)` + offset 2px | Stripe: فوکوس رینگ واقعی و ۳px |
| کانتینر | `1180px` | `1266px` (`--container`) | اندازه‌گیری‌شده از Stripe |
| تاپ‌بار | `66px` | `64px` | هدر چسبان نازک |

**رنگ برند عمداً دست نخورد** (`#0f7a6a`). درس اصلی تحقیق: سیستم کپی می‌شود، نه هیوِ رنگ.

## باگ‌هایی که در همین مسیر پیدا و رفع شد

1. **سرریز افقی در موبایل** (`scrollWidth 533` روی ویوپورت ۳۹۰): گریدهای ۳ ستونی با `grid-template-columns: 1fr` جمع می‌شدند ولی فرزندان `minmax(0,1fr)` نبودند، پس محتوای پهن آن‌ها را می‌کشید بیرون. رفع: `minmax(0, 1fr)` در بریک‌پوینت‌های ۱۱۰۰ و ۶۴۰.
2. **تاپ‌بار خالی در موبایل**: `hide-sm` روی عنوان فروشگاه اعمال می‌شد. رفع: استثنا برای `.topbar .hide-sm`.
3. **صفحه‌ی ورود بی‌استایل**: `landing.css` کلاس‌های `auth-*` را هم دارد؛ هنگام بازنویسی، بلوک auth هم بازنویسی و بازگردانده شد (و با توکن‌های جدید هماهنگ شد).

## چطور محلی ببینی

```bash
cd frontend
npm install
npm run dev        # http://localhost:3000
```

`/app` و `/app/products` نیاز به بک‌اند (`:3001`) و لاگین دارند. برای دیدن سریع ظاهر بدون بک‌اند، `/` و `/login` کافی است.

## مرحله‌ی دوم — پنل هم بازطراحی شد

دفعه‌ی قبل فقط توکن‌ها عوض شده بود، پس داشبورد «هیچ تغییری» نداشت. این بار خودِ کامپوننت‌ها هم بازنویسی شدند:

| کامپوننت | قبل | بعد |
|---|---|---|
| `StatCard` | کارت جدا با آیکون رنگی و عدد وزن ۸۰۰ | عضوی از **نوار آمار هایرلاین** (`.stat-strip`) با عدد **وزن ۳۰۰** و آیکون ۲۶px بی‌رنگ |
| کارت‌های داشبورد | `box-shadow` + `card-foot` خاکستری | فقط خط مویی + فوتر شفاف |
| فهرست‌ها | آواتار ۳۴px با شعاع ۱۰ | آواتار ۳۰px با شعاع ۴، عنوان وزن ۵۰۰، زیرنویس وزن ۳۰۰ |
| بَج‌ها | وزن ۶۰۰، پدینگ ۹px | وزن ۵۰۰، پدینگ ۹px، پایان‌های ۱۱٫۵px |
| Segmented | شعاع ۶ روی ترک | ترک **پیل** با سگمنت فعال سفید (الگوی تب FlowNinja) |
| نمودار | میله‌ی گرادیانی با ترک گرادیانی و شعاع ۷ | میله‌ی تخت `--brand-400` با ترک `--surface-3` و شعاع ۳ |
| Progress | ارتفاع ۷px گرادیانی | ارتفاع ۴px تخت |
| حباب چت | گرادیان + سایه‌ی برند | تخت `--brand`، شعاع ۱۰ با گوشه‌ی ۳ |
| جدول | هدر خاکستری | هدر شفاف، بدنه وزن ۳۰۰ |
| کارت بنر پایانی داشبورد | گرادیان سبز تیره | **نوار تیره‌ی سرمه‌ای** (`--night`) — همان وارونگی FlowNinja |
| `/app/products` | هر محصول یک کارت جدا | **یک کارت با ردیف‌های هایرلاین** و هاور `#F8FAFC` |
| Empty state | آیکون ۵۶px با گرادیان | آیکون ۴۴px با قاب خط‌مویی |
| Modal / Toast | شعاع ۲۴/۱۴ + سایه‌ی رنگی | شعاع ۱۰/۶ + سایه‌ی خنثی |

هر پنج صفحه دوباره بازبینی شدند: `/`, `/login`, `/app`, `/app/products`, `/app/import`, `/app/assistant`, `/app/settings` — در ۱۴۴۰ و ۳۹۰، بدون سرریز افقی (`scrollWidth == clientWidth`).

## مرحله‌ی سوم — بقیه‌ی صفحات

| صفحه | چه شد |
|---|---|
| هدر همه‌ی صفحات | `PageHeader` حالا **برچسب بالای تیتر** + تیتر وزن ۳۰۰ + توصیف وزن ۳۰۰ دارد و با یک **خط مویی** از محتوا جدا می‌شود (الگوی بخش‌بندی Stripe). |
| `/app/settings` | کارت‌ها شماره‌ی بخش گرفتند (`۰۱`, `۰۲`, `حساب`) در گوشه‌ی هدر کارت؛ پیش‌نمایش پاسخ‌ها از جعبه‌های رنگی به **ردیف‌های کلید/مقدار خط‌مویی** تبدیل شد و مقادیر خالی با رنگ کهربایی مشخص می‌شوند؛ کارت گرادیانی «فروشگاه فعلی» به کارت خط‌مویی با ردیف‌های نام/شناسه/وضعیت و بَج «فعال» شد؛ «کامل‌بودن پروفایل» عدد ۳۴px وزن ۳۰۰ گرفت. |
| `/app/import` | `name/price/stock/size/color/sku` حالا در **ستون راست** و بَج الزامی/اختیاری در ستون چپ (قبلاً برعکس و شلوغ بود)؛ برچسب `CSV / XLSX` در هدر کارت؛ آیکون‌ها و شعاع‌ها با بقیه یکی شد. |
| `/app/assistant` | فهرست «دستیار چطور تصمیم می‌گیرد» به **لیست شماره‌دار خط‌مویی** با دایره‌های ۲۰px تبدیل شد؛ نمونه‌سؤال‌ها از بَج خاکستری به **چیپ پیل** با هاور؛ تیترهای کارت وزن ۵۰۰؛ آواتار گفتگو کوچک و بی‌رنگ‌تر. |

همه‌ی صفحات در ۱۴۴۰ و ۳۹۰ بازبینی شدند؛ `scrollWidth == clientWidth` در هر ده حالت.

## چه چیزی هنوز باقی مانده

- صفحه‌ی `/app/products` از نظر ساختاری همان است (فقط توکن‌ها و شعاع/سایه/وزن عوض شده). اگر بخواهی، جدول/کارت‌ها را به الگوی «ردیف‌های خط‌کشی + هاور `#F8FAFD`» نزدیک می‌کنم.
- `demo.html` (فایل مرجع) را نگه داشتم تا مقایسه‌ی قبل/بعد ممکن باشد.
