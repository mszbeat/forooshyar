# تحلیل UI/UX دو مرجع: **Stripe** و **FlowNinja**
### برداشت الگو، اندازه‌گیری، و کپی‌برداری برای محصول خودمان

> این سند نتیجه‌ی یک بررسی واقعی است، نه مرور چشمی: هر دو سایت با مرورگر واقعی (Playwright, Chromium) در دو اندازه‌ی **۱۴۴۰×۹۰۰** و **۳۹۰×۸۴۴** باز شدند، تا ته صفحه اسکرول شدند تا محتوای تنبل‌بارگذاری هم لود شود، سپس تمام استایل‌های محاسبه‌شده (`getComputedStyle`) استخراج و رفتارهای تعاملی (هدر، منو، هاور، فوکوس، تب، آکاردئون) تست شد.

## ۰. تصویر کلی در یک نگاه

| | **Stripe** | **FlowNinja** |
|---|---|---|
| زبان | سفید، مهندسی‌شده، «سند فنی» | تیره، سینمایی، «کمپین تبلیغاتی» |
| قهرمان صفحه | **تیپوگرافی سبک و بزرگ** + آرت گرادیانی | **تیپوگرافی غول‌پیکر** + موزاییک کار مشتری |
| وزن فونت تیتر | **300 (Light)** — نقطه‌ی تمایز اصلی | 400–600 |
| فاصله‌ی حروف | منفی و نامحسوس (−۰٫۰۲em) | ۰ (فقط روی لاتین −۰٫۰۳em) |
| شعاع گوشه | ۴px دکمه، ۶px کارت | ۸px (غالب)، ۴px، پیل ۱۴۴۰px |
| سایه | کم و نرم، فقط برای شناوری | تقریباً هیچ؛ همه‌چیز با **خط مویی** جدا می‌شود |
| اکسنت | یک بنفش اشباع: `#533AFD` | آبی برند `#1A78FB` + لهجه‌ی صورتی `#F1C4FA` |
| ریتم | ستون ۱۲۶۶px + ستون متن ۱۰۲۴px با **خطوط عمودی ۱px** | کانتینر ۱۲۸۰px، پدینگ ۸۰px، بدون خط عمودی |
| هدر | **غیرچسبان** (position: relative) ۷۶px | **چسبان** ۱۱۱px با انیمیشن |
| حس نهایی | «چیز جدی و دقیق است» | «چیز هیجان‌انگیز و گران است» |

هر دو در یک چیز اشتراک دارند و آن هم مهم‌ترین درس است: **هیچ‌کدام تزئینی نیستند؛ همه‌ی جزئیات از یک نظم مشخص پیروی می‌کنند.** کیفیت حاصل «چیزهای خیلی خاص» نیست، حاصل **تکرار بی‌خطای یک سیستم کوچک** است.

## ۱. Stripe — کالبدشکافی کامل

### ۱.۱ تیپوگرافی (مهم‌ترین بخش)
| نقش | اندازه / line-height | وزن | letter-spacing |
|---|---|---|---|
| H1 هیرو | 48px / 1.15 (55.2) | **300** | −0.96px (−0.02em) |
| H2 | 32px / 1.10 | 300 | −0.64px |
| H2 بزرگ | 56px / 1.03 | 300 | −1.4px |
| H3 | 26px / 1.12 | 300–400 | −0.26px |
| پاراگراف هیرو | 22px / 1.10 | **300** | ۰ |
| پاراگراف متن | 18px / 1.40 و 16px / 1.40 | **300** | ۰ |
| لینک ناوبری | 14px | 400 | ۰ |
| دکمه | 16px (هیرو) / 14px (هدر) | ۴۰۰–۵۰۰ | ۰ |

قواعد قابل کپی:
1. **تیتر بزرگ + وزن نازک.** اکثر محصولات برعکس عمل می‌کنند (تیتر بزرگ + وزن ۷۰۰) و نتیجه «فریاد» می‌شود؛ Stripe «نجوا با اعتماد» می‌کند.
2. **فاصله‌ی حروف منفی کوچک** (−۰٫۰۲ تا −۰٫۰۳em) روی لاتین. این کار تیتر را «دقیق» نشان می‌دهد، نه شلخته.
3. **line-height پایین (۱٫۱–۱٫۱۵) برای تیتر، ۱٫۴ برای متن.** کنتراست عمودی زیاد.
4. **حداکثر عرض متن ۹۶۰–۱۰۲۴px.** هیچ پاراگرافی تمام‌عرض نیست.

### ۱.۲ رنگ
```
#FFFFFF  #F8FAFD  #E5EDF5            ← رمپ خنثی مایل به آبی
#061B31  #50617A  #64748D            ← سه سطح متن (تیتر / متن / کم‌رنگ)
#533AFD  #7F7DFC  #2C2484  #122054    ← اکسنت و عمق آن
rgba(21,190,83,.2)                   ← پیل موفقیت (سبز شفاف)
```
- **یک** رنگ اکسنت، در **دو** نقش: پُر (دکمه‌ی اصلی) و شفاف (پیل‌ها، پس‌زمینه‌ی نشان‌ها).
- متن هرگز `#000` نیست؛ `#061B31` است (سرمه‌ای تیره) — همین یک تصمیم، کل سایت را «گران» می‌کند.
- آبجکت‌های سه‌بعدی و گرادیان‌ها همه در خانواده‌ی بنفش/آبی می‌مانند؛ هیچ رنگ چهارمی اضافه نمی‌شود.

### ۱.۳ فرم و عمق
- شعاع‌ها: **4px** (۶۵ بار) و **6px** (۹۲ بار). یعنی عملاً «تقریباً تیز». خبری از ۱۶px و ۲۴px نیست.
- سایه‌ها فقط دو تا و هر دو نرم: `0 16px 32px rgba(50,50,93,.12)` و `0 15px 35px rgba(23,23,23,.08)`.
- جداکننده‌ها **خط مویی ۱px** با رنگ `#E5EDF5` هستند، نه سایه و نه کارت.
- دکمه‌ی ثانویه = **متن بنفش روی زمینه‌ی شفاف** (نه دکمه‌ی خاکستری). دکمه‌ی outline = حاشیه‌ی `rgba(255,255,255,.1)` + متن بنفش.

### ۱.۴ چیدمان
- کانتینر ۱۲۶۶–۱۲۹۸px، ستون متن ۱۰۲۴px با **آفست ≈۲۰۸px از راست**.
- **خطوط عمودی ۱px** که از میان بخش‌ها رد می‌شوند و ستون‌بندی را «قابل دیدن» می‌کنند — ارزان‌ترین راه برای اینکه یک صفحه‌ی سفید خالی «طراحی‌شده» به نظر برسد.
- هیرو: برچسب زنده + تیتر **دورنگ** (ادعای تیره + ادامه‌ی خاکستری/گرادیانی) + آرت گرادیانی که از لبه‌ی صفحه بیرون می‌زند (overflow: clip).
- نوار لوگوها با حاشیه‌ی بالا/پایین و تقسیم‌بندی عمودی — لوگوها خاکستری‌اند و با هاور تیره می‌شوند.

### ۱.۵ تعامل و دسترس‌پذیری
- فوکوس رینگ واقعی و ضخیم: `outline: 3px solid rgba(84,82,251,.75)`. یعنی فوکوس با کیبورد **دیده می‌شود** (خیلی از سایت‌ها این را حذف می‌کنند).
- هدر غیرچسبان است؛ به‌جایش «توست» گوشه‌ی صفحه (لوکال/کشور) برای یک اقدام جانبی.
- تب‌های آمار به‌صورت متن‌های کلیک‌شدنی با آندرلاین نازک، نه دکمه.

**نقطه‌ضعف قابل ذکر:** هدر غیرچسبان یعنی در صفحه‌های بلند، CTA همیشه در دسترس نیست. برای یک اپ SaaS (که کاربرش مدام داخل پنل است) بهتر است الگوی FlowNinja را بگیریم: هدر چسبان، ولی نازک و بی‌سر‌و‌صدا.

## ۲. FlowNinja — کالبدشکافی کامل

### ۲.۱ تیپوگرافی
- فونت: **TWKLausanne** (400/600) + فونت‌های نمایشی (Empire، Alansans) فقط برای لوگو و تیترهای ویژه.
- H1 **76.8px**، وزن ۶۰۰، **line-height ۱٫۰** (بله، یک!) و حداکثر عرض ۵۷۶px → تیتر ۳ خطی و «دیواری» می‌شود.
- H2 76.8–80px با letter-spacing −۲٫۳px (−۰٫۰۳em).
- متن بدنه 16/24؛ تیتر کارت 20/26 با **وزن ۴۰۰** (نه بولد!) — همان درسِ «نجوا با اعتماد».
- برچسب‌ها بسیار کوچک (12px) و کم‌رنگ.

### ۲.۲ رنگ و سطح
```
#08163C  پس‌زمینه‌ی اصلی (سرمه‌ای تیره)   #F8F8F8  متن
rgba(255,255,255,.2)  ← ۹۵ بار! تمام خطوط جداکننده
rgba(255,255,255,.1)  ← ۲۴ بار، جداکننده‌های فرعی
#1A78FB #1F6ADC #488EEF  ← آبی برند در سه پله
#F1C4FA  ← لهجه‌ی صورتی (کم، فقط برای تضاد)
```
- **هیچ سایه‌ای.** همه‌ی تفکیک‌ها با **خط مویی سفید شفاف**. نتیجه: صفحه تیره عمق پیدا می‌کند بدون اینکه «شلوغ» شود.
- **یک بار وارونگی تیره→روشن** در میانه‌ی صفحه (`#F8F8F8`). این ترفند ساده، ریتم صفحه‌ی بلند را می‌شکند.
- **CTA سفید پیل‌شکل** تنها عنصر پرکنتراست صفحه است؛ همه‌ی مسیر نگاه به آن ختم می‌شود.

### ۲.۳ چیدمان و بلوک‌ها
- کانتینر ۱۲۸۰px، مارجین ۸۰px، پدینگ‌پایین بخش‌ها ۸۰px.
- هدر: نوار اعلان ۴۷px + نوار اصلی ۱۱۱px، `position: sticky`، شفاف، با `transition: top .35s`.
- هیرو دو ستونی: متن راست، **موزاییک عمودی از تصاویر کار مشتری** در چپ (چیدمان masonry، نه گرید منظم) — «کار واقعی» جای «شکل هندسی انتزاعی».
- **نوار آمار با خط مویی:** `$100K / 16 / 21.4% / 300+` — فقط عدد و یک برچسب کوچک، بدون آیکون و رنگ.
- **گرید قابلیت ۶ سلولی** با خطوط مویی (همان الگوی «جدول» Stripe، تیره‌شده).
- **تب‌سوییچر پیل** برای سرویس‌ها (در صفحه‌ی تعرفه هم تکرار می‌شود: «One time projects / Ongoing retainers» با سگمنت سفید).
- کارت‌های نمونه‌کار با **گرادیان دو‌رنگ** + نقل‌قول + لوگو + عدد نتیجه.
- کارت‌های ویدیو-شهادت با لوگوی برند در بالا و چیپ «Play video» — یعنی «شهادت» تعاملی است نه متن مرده.
- بلوک‌های جایزه/نظر/محصول/CTA وسط‌چین؛ فوتر ۵ ستونی مگا.

### ۲.۴ تعامل
- تب‌سوییچر پیل با حالت فعال **سفید پر** در دل تیره (کنتراست حداکثری = وضوح انتخاب).
- هاور کارت = تغییر بسیار ملایم پس‌زمینه/حاشیه، بدون حرکت آزاردهنده.
- **نبود فوکوس رینگ مشخص** ← این را کپی نکنید.

## ۳. مقایسه‌ی رو‌در‌رو: چه چیزی را از کدام بگیریم؟

| تصمیم طراحی | Stripe | FlowNinja | توصیه برای فروشیار |
|---|---|---|---|
| وزن تیتر | 300 | 400–600 | **300** (Stripe) روی فارسی هم فوق‌العاده است؛ وزن ۳۰۰ وزیرمتن تمیز و «گران» است |
| اندازه‌ی H1 | 48px | 76.8px | **۴۸–۵۶px** برای پنل داخلی، ۶۴px فقط برای لندینگ |
| شعاع | ۴/۶px | ۸px | **۴px دکمه، ۶px کارت، پیل برای چیپ‌ها** |
| تفکیک | خط مویی + سایه‌ی کم | فقط خط مویی | **خط مویی به‌عنوان پیش‌فرض**، سایه فقط برای عناصر شناور (مودال، پاپ‌اور، دراپ‌داون) |
| هدر | غیرچسبان | چسبان | **چسبان ولی نازک** (۶۴px، blur، حاشیه‌ی مویی) |
| رنگ | تک‌اکسنت بنفش | آبی + لهجه‌ی صورتی | تک‌اکسنت + دو پله‌ی همان رنگ + یک لهجه‌ی خیلی کم‌مصرف |
| اثبات | آمار + لوگوی مشتری | کارت نتیجه‌ی مشتری + ویدیو | **هر دو**: آمار عددی + کارت نقل‌قول با عدد نتیجه |
| وارونگی تیره | ندارد (همه سفید) | یک بخش کامل | یک بخش تیره در میانه‌ی لندینگ، دقیقاً یکی |
| تصویر | آرت گرادیانی انتزاعی | کار واقعی مشتری | **گرادیان + اسکرین‌شات محصول** (نه تصویر استوک) |
| دسترس‌پذیری | فوکوس رینگ واقعی | ندارد | **از Stripe** |

### ترکیب پیشنهادی (همان که در `demo.html` پیاده شده)
`Stripe` برای **سیستم** (تایپ، رنگ، شعاع، خطوط، دسترس‌پذیری) + `FlowNinja` برای **ریتم و هیجان** (هیرو دو ستونی، وارونگی تیره، نوار آمار، تب پیل، کارت‌های گرادیانی).

## ۴. هفت قانونی که هر دو سایت رعایت می‌کنند (و اکثر سایت‌های ایرانی نمی‌کنند)

1. **یک اکسنت، حداکثر.** رنگ فقط جایی که باید کلیک شود.
2. **متن هرگز سیاه مطلق نیست** و پس‌زمینه هرگز سفید مطلق نیست (کمترین انحراف رنگی، بیشترین حس کیفیت).
3. **وزن نازک + اندازه‌ی بزرگ** به‌جای وزن ضخیم + اندازه‌ی متوسط.
4. **کمترین شعاع ممکن.** گوشه‌های خیلی گرد = ارزان‌تر به نظر می‌رسد.
5. **جداکننده‌ها ۱px هستند**، نه سایه، نه کارت رنگی، نه آیکون.
6. **هر عدد، یک برچسب کوچک.** «۲۴٪» بدون توضیح، تزئین است.
7. **سلسله‌مراتب با فاصله ساخته می‌شود، نه با رنگ.** فاصله‌های ۸/۱۶/۲۴/۳۲/۴۸/۸۰/۱۰۴ یک مقیاس است، نه سلیقه.

## ۶. یافته‌های تست تعاملی (چیزی که در اسکرین‌شات دیده نمی‌شود)

- **هدر:** FlowNinja با `transition: top .35s` جابه‌جا می‌شود (جاخالی می‌دهد و برمی‌گردد)؛ Stripe اصلاً چسبان نیست.
- **مگامنو:** FlowNinja پنل تمام‌عرض با ستون‌بندی باز می‌کند؛ اسکرین‌شات‌های `mega-menu.png` در پوشه **معتبر نیستند** (اسکریپت تشخیص، یک کلاس شبیه `stats-menu` را گرفته بود). برای بازسازی، باید روی خود آیتم «Services» کلیک شود.
- **فوکوس:** Stripe رینگ ۳px با آلفای ۰٫۷۵ دارد؛ FlowNinja عملاً ندارد.
- **هاور دکمه:** هر دو فقط تغییر رنگ/سایه‌ی ملایم؛ هیچ‌کدام بزرگ‌نمایی یا انیمیشن بونس ندارند.
- **سایه‌ی کارت:** Stripe ۹۲ کارت با شعاع ۶px و سایه‌ی نرم؛ FlowNinja ۱۲۱ المان با شعاع ۸px و **صفر** سایه.
- **خطای صفحات:** هیچ خطای کنسولی در هیچ‌کدام ثبت نشد (سایت‌ها تمیز اجرا می‌شوند).

> نکته‌ی فنی: بنر کوکی FlowNinja گوشه‌ی اسکرین‌شات‌ها را پوشانده است؛ در `demo.html`، الگوی «توست گوشه» را عمداً با دکمه‌ی بستن پیاده کردم.

## ۷. ترجمه به فارسی و RTL — چه چیزی باید عوض شود

| موضوع | در سایت مرجع | در فارسی/RTL |
|---|---|---|
| letter-spacing | −۰٫۰۲em | **۰** یا حداکثر ۰٫۰۱em مثبت (منفی، اتصال حروف فارسی را زشت می‌کند) |
| line-height تیتر | ۱٫۰–۱٫۱۵ | **۱٫۱۵–۱٫۲۵** (فارسی کشیدگی زیر دارد و در ۱٫۰ روی هم می‌افتد) |
| وزن | ۳۰۰ | همان ۳۰۰، ولی با فونت فارسی دارای وزن Light واقعی (وزیرمتن) |
| جهت آیکون | ← | در RTL فلش «جلو» باید **به چپ** باشد؛ آیکون‌های دارای جهت باید `transform: scaleX(-1)` شوند (به‌جز ساعت، پخش، لوگو) |
| اعداد | 1,234.5 | **۱۲٬۳۴۵** با ممیز فارسی «٬» و `unicode-bidi: plaintext` تا اعداد در متن مختلط نپرانند |
| تراز | راست‌چین طبیعی | `text-align: start` + `dir="rtl"` روی `<html>`، و استفاده از `margin-inline`/`inset-inline` (نه left/right) |
| فونت | sohne-var | وزیرمتن (۵ وزن، ساب‌ست‌شده ≈ ۲۴KB هر وزن، در `fonts/`) |

## ۹. چه چیزی را کپی **نکنید**

1. **تیتر ۷۶px با line-height ۱٫۰ برای فارسی** — روی هم می‌افتد.
2. **هدر غیرچسبان Stripe** برای اپ داخلی — کاربر باید همیشه بتواند برگردد/اکشن کند.
3. **حذف فوکوس رینگ** به سبک FlowNinja.
4. **۹۵ خط مویی سفید** به‌عنوان تنها ابزار تفکیک در پنل داده — روی جدول‌های پر از داده، خسته‌کننده می‌شود؛ در پنل، خط + فضای سفید کافی است.
5. **آرت انتزاعی بدون اسکرین‌شات محصول.** Stripe می‌تواند چون برندش تثبیت است؛ ما باید اول محصول را نشان دهیم.
6. **تیتر ۳ خطی وسط‌چین با متن طولانی** — برای فارسی که جمله‌اش بلندتر می‌شود، عنوان کوتاه و چپ‌چین (RTL: راست‌چین) بهتر جواب می‌دهد.
